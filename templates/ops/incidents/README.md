# 겪은 일

**코드나 ADR 로는 남지 않는 것을 적습니다.** 시간이 지나면 재구성할 수 없습니다.

한 건에 파일 하나, 이름은 `YYYY-MM-DD-한줄요약.md`.

## 무엇을 적나

```markdown
# 무슨 일이 있었나

## 증상
화면에 무엇이 보였나. 오류 메시지 그대로.

## 진짜 원인
겉으로 보인 것과 다를 수 있다. 그 차이를 적는다.

## 어떻게 알아냈나
무엇을 보고 알았나. 다음 사람이 같은 길을 밟을 수 있게.

## 고친 것
## 남은 것
```

## 예: 낡은 워커가 엉뚱한 진단을 냈다

증상은 `bundle_layout_invalid` - "zip 최상위에 `.app` 하나만 담아 다시 올리세요"
였는데, **파일은 멀쩡한 dmg 였습니다.** 진짜 원인은 워커가 dmg 지원이 들어가기 3시간
반 전에 빌드된 것이었고, 받은 것을 무조건 `ditto` 로 풀려다 실패한 것이었습니다.

이런 것은 코드를 봐서는 알 수 없습니다. 그래서 여기 적습니다.
