# 서버 올리기

보통은 **할 일이 없습니다.** `adopt.yml` 이 `scripts/rollout-server.sh` 를 부릅니다.
그 스크립트를 조직 환경에 맞게 채워두면 됩니다 (`rollout-server.sh.example` 참고).

## 마이그레이션

서버는 기동할 때 마이그레이션을 적용할 수 있습니다(`MIGRATE_ON_BOOT`). 켜져 있으면
롤아웃마다 돌고, 실패하면 서버가 뜨지 않습니다.

일회성 명령을 돌릴 수 있는 환경이면 그 값을 끄고 이렇게 하는 편이 낫습니다.

```bash
<플랫폼 명령> alley-server migrate --yes
```

## 되돌리기

이미지 태그를 이전 것으로 되돌립니다. **마이그레이션은 저절로 되돌아가지 않습니다.**
칼럼을 추가하는 마이그레이션은 옛 서버도 그냥 돌지만, 이름을 바꾸거나 지우는
것이었다면 되돌리기 전에 확인해야 합니다.

```bash
<플랫폼 명령> alley-server migrate --revert --yes
```
