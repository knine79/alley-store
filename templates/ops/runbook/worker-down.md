# 워커가 멈췄을 때

## 먼저 볼 것

관리 > 서명 워커 화면입니다.

| 보이는 것 | 뜻 |
| --- | --- |
| 마지막 접속이 오래됨 | 프로세스가 죽었거나 맥이 꺼졌거나 네트워크가 막혔다 |
| 워커 버전이 빨감 | 돌고는 있는데 낡았다. **엉뚱한 실패를 낼 수 있다** |
| 작업 중인데 안 끝남 | 공증을 기다리는 중일 수 있다 (몇 분~수십 분) |

## 낡은 워커는 조용히 엉뚱한 실패를 냅니다

dmg 를 모르는 워커가 dmg 를 zip 으로 풀려다 실패하면서 "번들 구조 문제" 라는 엉뚱한
진단을 낸 적이 있습니다. 올린 사람은 멀쩡한 파일을 몇 번이나 다시 만들었습니다.

**실패 원인을 보기 전에 워커 버전부터 확인하세요.**

## 맥에서 볼 것

```bash
launchctl list | grep alley
tail -100 ~/Library/Logs/alley-worker/worker.log
```

## 자주 나오는 것

**키체인이 잠겨 있다** — 재부팅 뒤 아무도 로그인하지 않으면 이렇게 됩니다. 서명이
`User interaction is not allowed` 로 죽습니다. **자동 로그인을 켜두세요.**

**공증 자격증명이 없다** — `xcrun notarytool history --keychain-profile <이름>` 으로
확인합니다. data-protection 키체인에 있어서 Keychain Access 로는 안 보입니다.

**토큰이 폐기됐다** — 관리 화면에서 새로 발급하고 워커 설정 파일을 고칩니다.
