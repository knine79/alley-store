# ADR-0064: CLI 는 토큰을 브라우저에서 받아온다

- 상태: 수락됨
- 날짜: 2026-09-28

## 맥락

`alley mcp` 를 붙이려면 사람 토큰이 있어야 합니다. 지금은 이렇게 합니다.

1. 웹 콘솔에 로그인한다
2. 내 설정 > 내 토큰에서 발급한다
3. 원문을 복사한다
4. `claude mcp add` 명령에 붙여넣는다

**네 단계 내내 자격증명이 사람 손을 탑니다.** 클립보드에 남고, 셸 히스토리에
남고, 붙여넣다 실수하면 채팅창이나 이슈에 남습니다. 이 세션에서도 그렇게 새었습니다.

다른 MCP 서버들은 붙일 때 브라우저가 뜨고 버튼 하나를 누르면 끝납니다. 사람이
토큰을 보지도 만지지도 않습니다.

## 결정

**`alley auth login` 이 브라우저를 열어 토큰을 받아옵니다.**

```
alley auth login
  1. CLI 가 127.0.0.1 의 빈 포트를 잡고 기다린다
  2. 브라우저로 /auth/cli?port=NNN&state=XXX 를 연다
  3. 로그인이 안 돼 있으면 여느 화면처럼 OIDC 로 보냈다 돌아온다
  4. "이 기기를 연결합니다" 를 묻는다
  5. 누르면 일회용 코드를 127.0.0.1:NNN 으로 돌려보낸다
  6. CLI 가 그 코드를 POST 로 교환해 사람 토큰을 받는다
  7. ~/.config/alley/credentials 에 0600 으로 저장한다
```

### 긴 수명 토큰을 URL 에 싣지 않습니다

돌아오는 주소에 실리는 것은 **2분 사는 일회용 코드**입니다. 90일 사는 토큰을 URL
에 실으면 브라우저 기록과 시스템 로그에 남습니다. 스토어 앱이 세션 토큰을 받아갈
때 이미 같은 이유로 같은 구조를 씁니다 (`AuthCode`). 그것을 그대로 씁니다.

### `state` 로 콜백을 지킵니다

루프백 주소는 이 기계의 아무 프로세스나 부를 수 있습니다. CLI 가 무작위 `state`
를 만들어 보내고 돌아온 값과 대조합니다. 맞지 않으면 버립니다.

### 기기 이름은 짓지 않고 만들어 줍니다

`호스트명-짧은해시` 입니다. 예: `Knineui-MacBookPro-a3f9`.

이름을 물으면 단계가 하나 늘고, 대개 아무 이름이나 적습니다. 그렇다고 호스트명만
쓰면 같은 맥에서 둘을 연결한 순간 목록에서 구별되지 않아 **무엇을 폐기할지 고를 수
없습니다** (ADR-0055 가 이름이 겹치면 안 되는 이유로 든 것과 같습니다). 연결할
때마다 다른 해시를 붙여 그 일이 생기지 않게 합니다.

### 파일에 0600 으로 둡니다

`~/.config/alley/credentials` 에 서버 주소별로 적습니다.

`CLIConfig` 는 지금까지 환경변수만 읽었고, 그 이유로 "설정 파일을 두면 그 파일에
토큰이 남아 커밋될 위험이 있다" 를 적어뒀습니다. **그 걱정은 레포 안에 두는 파일
이야기입니다.** 홈 아래 0600 파일은 다릅니다. `gh`, `aws`, `docker` 가 모두 같은
자리에 같은 방식으로 둡니다.

환경변수가 있으면 환경변수가 이깁니다. CI 는 사람이 앉아 있지 않아 브라우저를
열 수 없고, 거기서는 배포 토큰을 환경변수로 주는 것이 맞습니다.

## 대안과 기각 사유

### 지금처럼 복사해서 붙여넣는다

**만들 것이 없습니다.** 화면도 이미 있고 사람도 한 번 해봤으면 압니다.

기각한 이유는 자격증명이 사람 손을 타는 것 자체가 문제이기 때문입니다. 클립보드와
셸 히스토리는 지우기도 어렵고, 지웠는지 확인할 방법도 없습니다.

### 기기 코드 방식 (`alley auth login` 이 코드를 보여주고 사람이 브라우저에 친다)

**포트를 열지 않습니다.** 원격 셸이나 컨테이너처럼 브라우저와 CLI 가 다른 기계에
있어도 됩니다. GitHub CLI 가 이 방식입니다.

기각한 이유는 우리 쓰임이 대부분 같은 맥이어서입니다. 루프백이면 사람이 숫자를
옮겨 적지 않아도 되고, 원격에서 붙일 일이 생기면 그때 더해도 늦지 않습니다.

### 긴 수명 토큰을 콜백 주소에 바로 싣는다

**교환 단계가 없어 간단합니다.** 서버도 CLI 도 한 번씩 덜 부릅니다.

기각한 이유는 그 값이 90일을 살기 때문입니다. 브라우저 기록에 남고, 리버스 프록시
로그에 남고, 어깨너머로 보입니다. 스토어 앱에서 이미 같은 이유로 코드를 한 번
거치기로 했습니다.

### 키체인에 넣는다

macOS 전용 도구라면 키체인이 제자리입니다. 디스크에 평문으로 남지 않습니다.

기각한 이유는 둘입니다. `alley` 는 리눅스 CI 에서도 도는 명령이라 한쪽에만 있는
저장소를 기본으로 삼을 수 없습니다. 그리고 키체인은 **무엇이 들어 있는지 눈으로
확인하기 어렵습니다.** 붙지 않을 때 사람이 먼저 하는 일이 파일을 열어보는 것인데
그 길이 막힙니다.

## 나쁜 점

**브라우저가 없는 곳에서는 못 씁니다.** SSH 로 들어간 서버나 컨테이너에서는
`alley auth login` 이 열 브라우저가 없습니다. 그때는 환경변수로 주는 길이 그대로
남아 있지만, 그 길로 가려면 여전히 사람이 토큰을 복사해야 합니다.

**파일이 평문입니다.** 0600 이라 다른 사용자는 못 읽지만, 이 계정으로 도는 다른
프로그램은 읽습니다. 키체인보다 약합니다.

**포트를 잠깐 엽니다.** `state` 로 지키지만 여는 것은 여는 것입니다. 기다리는
시간에 상한을 두어 오래 열려 있지 않게 합니다.

**연결할 때마다 토큰이 하나씩 늘어납니다.** 같은 맥에서 여러 번 연결하면 쓰지 않는
토큰이 목록에 쌓입니다. 이름에 붙는 해시로 구별은 되지만 치우는 것은 사람 몫입니다.
