# ADR-0041: 어떤 앱이든 지울 수 있게 하되, 문턱을 서버에 둔다

- 상태: 수락됨
- 날짜: 2026-09-11
- 대체: [ADR-0039](0039-remove-unconfirmed-registrations.md)

## 맥락

[ADR-0039](0039-remove-unconfirmed-registrations.md) 는 **확정 전 등록만** 지울 수
있게 했습니다. 확정된 앱은 누군가 설치했을 수 있으니 건드리지 않는 쪽이 안전하다고
봤습니다.

하루도 못 가서 막혔습니다. 번들 ID 는 등록 뒤에 바꿀 수 없어서, **오타 하나로 만든
앱이 영영 목록에 남습니다.** 이 스토어에 앱을 올리는 사람은 macOS 개발자가 아니라
AI 와 함께 만든 앱을 올리는 사람입니다. 시험 삼아 만든 앱, 이름을 잘못 붙인 앱,
번들 ID 를 잘못 넣은 앱이 계속 생깁니다. 그걸 못 치우는 스토어는 금방 쓰레기통이
됩니다.

한편 ADR-0039 에는 이런 대가를 적어뒀습니다.

> 확인 팝업은 스크립트가 있어야 뜹니다. 없으면 바로 지워집니다. (…)
> **"정말?" 은 브라우저에만 있습니다**

지우는 범위를 넓히면서 그 약한 문턱을 그대로 두면 안 됩니다.

## 결정

**어떤 앱이든 오너와 관리자가 지울 수 있습니다.** 대신 문턱을 둘로 나눕니다.

| 앱 | 문턱 |
| --- | --- |
| 한 번도 안 나갔고 받아간 기록도 없다 | 팝업에서 한 번 확인 |
| 한 번이라도 나갔거나 누가 받아갔다 | **앱 이름을 그대로 적어야 한다** |

**이름 검사는 서버가 합니다.** 팝업은 실수로 누르는 것을 막는 자리일 뿐이고, 진짜
문턱은 `AppRemoval.remove` 안에 있습니다. 스크립트가 안 돌아도, 누가 `curl` 로
찔러도 같은 검사를 지납니다.

### 무엇을 잃는지 숫자로 보여줍니다

"되돌릴 수 없습니다" 만으로는 무엇을 잃는지 모릅니다. 버전이 몇 개인지, 몇 번
받아갔는지를 지우기 전에 화면과 팝업 양쪽에 적습니다.

### 지우기는 맨 아래 자기 구역에 둡니다

출시·철회·토큰 발급 버튼들 사이에 끼워두면 실수로 누릅니다. 화면 맨 아래에 테두리를
두른 구역을 따로 만들고 거기에만 둡니다.

### 파일도 함께 지웁니다

버전의 아티팩트와 피드백 스크린샷까지 스토리지에서 지웁니다. **행을 먼저 지우면
어떤 오브젝트가 남았는지 알아낼 방법이 없어집니다.** 그래서 스토리지를 먼저
치웁니다. 반대 순서로 실패하면 행이 남아 다시 시도할 수 있습니다.

## 대안과 기각 사유

**ADR-0039 대로 확정 전만 지운다** — 가장 안전하고 코드도 이미 있습니다. 그러나
오타로 만든 앱을 영영 못 치웁니다. 그 앱은 아무도 설치할 수 없고 목록만 어지럽힙니다.

**지우지 말고 "내림(archive)" 을 만든다** — 되돌릴 수 있어 훨씬 안전합니다. 목록에서
빠지고 새 설치는 막히되 받아간 사람은 그대로 씁니다. **이게 더 나은 답일 수 있습니다.**
그러나 상태 하나와 그 상태를 다루는 화면·API·스토어 앱 쪽 처리가 따라옵니다. 지금
막힌 것은 "시험 삼아 만든 앱을 치우고 싶다" 이고, 그건 지우기로 풀립니다. 내린 앱을
다시 올리고 싶다는 요구가 실제로 생기면 그때 만듭니다.

**관리자만 지울 수 있게 한다** — 실수를 줄입니다. 그러나 자기가 만든 시험용 앱을
치우려고 매번 관리자를 찾아야 하면 아무도 안 치웁니다.

**팝업만으로 충분하다고 본다** — 코드가 가장 적습니다. 그러나 스크립트가 안 돌면
아무 확인 없이 지워집니다. 되돌릴 수 없는 일에 브라우저만 믿을 수는 없습니다.

## 결과

**좋은 점**

- **막다른 골목이 없어졌습니다.** 오타로 만든 앱도, 시험용 앱도 치웁니다
- 진짜 문턱이 서버에 있습니다. 스크립트가 없어도, API 를 직접 찔러도 같습니다
- 무엇을 잃는지 누르기 전에 숫자로 압니다
- 지우기가 다른 버튼과 섞이지 않습니다

**나쁜 점**

- **되돌릴 수 없습니다.** 이름을 정확히 적은 사람은 이미 마음을 먹은 사람이지만,
  그래도 실수는 가능합니다. 백업은 데이터베이스 쪽에만 있습니다
- **나간 앱을 지우면 받아간 사람의 업데이트가 끊깁니다.** 그 사람들의 맥에는 앱이
  그대로 남고 새 버전만 영영 오지 않습니다. 스토어가 그 사실을 알려줄 방법이 없습니다
- **이름으로 확인하는 것은 이름이 짧으면 약합니다.** "앱" 같은 이름은 실수로도
  칠 수 있습니다
- 앱 상세 화면을 그릴 때마다 버전과 받아간 기록을 셉니다. 지금 규모에서는 문제가
  아니지만 공짜는 아닙니다
- **스토리지 삭제가 실패해도 앱은 지웁니다.** 오브젝트가 남을 수 있고, 그때는 로그가
  유일한 단서입니다
