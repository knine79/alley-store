# ADR-0073: 스토어 앱이 다른 앱도 묻지 않고 업데이트하고, 그것만 사람이 끌 수 있다

- 상태: 수락됨
- 날짜: 2026-10-06

## 맥락

스토어 앱은 자기 자신만 묻지 않고 업데이트했습니다. 다른 앱은 목록에서 "업데이트" 를
눌러야 받았습니다. 그렇게 둔 이유는 셋이었습니다.

- 쓰고 있는 앱을 바꿔치면 저장하지 않은 작업이 날아갑니다
- 개발자가 직접 넣은 빌드를 덮어쓰면 그 빌드는 스토어 어디에도 없습니다
- 스토어 앱이 낡으면 다른 앱을 받는 길 자체가 낡으므로, 스토어 앱만 예외로 둡니다

운영에서 "앱들이 왜 자동으로 업데이트되지 않느냐" 는 질문이 나왔습니다. 사내 앱은 대개
최신을 쓰는 편이 낫고, 업데이트가 나와도 받는 사람이 누르기 전까지는 예전 버전이 남습니다.

## 결정

**스토어 앱 계정 메뉴에 "앱 자동 업데이트" 를 체크 항목으로 두고, 기본으로 켭니다.** 값은
그 맥의 `UserDefaults` 에 둡니다. **스토어 앱 자신의 자동 업데이트는 지금처럼 끌 수
없습니다.**

- 묻지 않고 받는 앱은 **업데이트 있음(`updateAvailable`)이면서 실행 중이 아닌 것**뿐입니다.
  설치된 것이 스토어보다 새것이거나 버전을 알 수 없으면 사람이 누를 때도 덮어쓸지 묻는데,
  그 경우는 그대로 묻는 쪽에 둡니다. 직접 넣은 빌드가 대개 여기 해당합니다
- 실행 중인 앱은 건너뛰고 다음 확인 때 다시 봅니다. 받기 직전에 한 번 더 봅니다
- 확인 시점은 기존의 30분 주기와 "스토어 업데이트 확인"(⌘R)입니다
- 다른 앱을 먼저 받고 스토어 앱을 나중에 갈아끼웁니다. 스토어 앱은 갈아끼우면서 종료하므로
  먼저 하면 그 차례의 앱 업데이트가 사라집니다. 사람이 받는 중이면 둘 다 미룹니다
- 하나씩 받고, 끝나면 몇 개를 받았는지 한 줄로 알립니다. 자동 업데이트는 떠 있던 오류 창을
  걷지 않습니다
- 한 번 누르는 "스토어 업데이트 확인" 과 켜두는 "앱 자동 업데이트" 가 같은 메뉴에 서서,
  둘 다 메뉴 항목 아래에 짧은 설명을 붙입니다. 앱 메뉴의 항목 이름도 "스토어 업데이트
  확인" 으로 맞춥니다

## 대안과 기각 사유

### 스토어 앱에 설정 창(⌘,)을 만든다

**맥 앱이 설정을 두는 관례적인 자리이고, 옵션이 늘어도 담을 곳이 생깁니다.**

기각한 이유는 옵션이 하나뿐이라서입니다. 창 하나를 새로 여는 것보다 계정 메뉴에 체크
항목 하나를 두는 편이 찾기도 쉽고 바꾸기도 빠릅니다. 옵션이 늘면 그때 옮깁니다.

### 스토어 앱 자동 업데이트도 끌 수 있게 한다

**앱을 쓰는 중에 스토어 앱이 다시 시작되는 것을 싫어하는 사람에게 선택지가 생깁니다.**

기각한 이유는 스토어 앱이 낡으면 다른 앱을 받는 길 자체가 낡기 때문입니다. 끈 사람의
스토어 앱은 서버가 바뀌어도 따라오지 못하고, 그 사실을 알아챌 길이 배너 하나뿐입니다.

### 관리자가 조직 전체에 정한다

**한 곳에서 정하면 조직 전체가 같은 버전을 쓰게 되고, 보안 수정을 빨리 퍼뜨릴 수 있습니다.**
웹 콘솔의 스토어 설정에 두고 `/meta` 로 내려주면 됩니다.

기각한 이유는 업데이트를 언제 받을지는 앱을 쓰는 사람의 사정이기 때문입니다. 발표 직전에
앱이 바뀌는 것을 싫어하는 사람도 있습니다. 서버 설정과 마이그레이션도 따라옵니다. 조직이
강제해야 할 일이 생기면 그때 기본값을 내려주는 길을 더할 수 있습니다.

### 실행 중인 앱은 종료를 물어 업데이트한다

**실행 중인 앱도 바로 최신이 됩니다.** 설계 문서의 교체 절차가 이미 그렇게 적혀 있습니다.

기각한 이유는 자동 업데이트가 확인 창을 띄우면 "묻지 않고" 가 아니게 되기 때문입니다.
30분마다 묻는 창이 뜨면 사람들은 끄거나 무시합니다. 실행 중인 앱은 사람이 직접 누르는
업데이트로 남깁니다.

### 덮어쓸지 묻던 경우도 자동으로 받는다

**스토어와 다른 빌드가 깔린 맥이 남지 않습니다.**

기각한 이유는 그 빌드가 개발자가 직접 넣은 것일 때가 많아서입니다. 사람이 누를 때도 묻는
것을 묻지 않고 하면 그 빌드가 말없이 사라집니다.

## 결과

**좋은 점**

- 업데이트가 나오면 실행 중이 아닌 앱은 30분 안에 최신이 됩니다
- 원하지 않는 사람은 계정 메뉴에서 바로 끌 수 있습니다

**나쁜 점**

- **늘 켜두는 앱은 자동으로 업데이트되지 않습니다.** 메뉴바 앱처럼 내내 떠 있는 앱은 실행
  중이라 계속 건너뜁니다. 그런 앱은 여전히 사람이 눌러야 합니다
- 스토어 앱이 다시 시작되는 것을 막을 길은 여전히 없습니다
- 설정이 맥마다 따로라 관리자는 누가 껐는지 알 수 없습니다
- 받는 중에 사람이 그 앱을 실행하면, 받기 직전 확인을 지난 뒤라 교체가 그대로 진행됩니다.
  창은 짧지만 없지는 않습니다

**후속**

- 늘 켜두는 앱을 위해, 실행 중이면 그 앱이 종료될 때 받는 길을 검토합니다
- 조직이 기본값을 정해야 할 일이 생기면 `/meta` 로 내려주는 길을 더합니다
