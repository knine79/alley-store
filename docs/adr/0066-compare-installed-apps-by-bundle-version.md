# ADR-0066: 설치된 앱은 번들의 CFBundleVersion 으로 견준다

- 상태: 수락됨
- 날짜: 2026-09-30

## 맥락

스토어 앱은 깔린 앱이 최신인지를 **깔린 번들의 `CFBundleVersion` 을 정수로 읽어 스토어의
빌드 번호와** 견줘서 판단했습니다. 두 가정이 들어 있었습니다.

1. `CFBundleVersion` 은 정수다
2. 스토어의 빌드 번호는 번들의 `CFBundleVersion` 과 같다

운영에 처음 올라온 사내 앱에서 둘 다 깨졌습니다. 번들의 `CFBundleVersion` 은 `1.8.25`
였고, 스토어는 그 버전에 빌드 번호 1 을 매겼습니다. 방금 설치한 앱이 "다시 설치" 로
보였습니다.

`1.8.25` 는 Apple 규격에 맞는 값입니다(점으로 나눈 정수 셋까지). 이렇게 적는 앱이 흔합니다.
두 번째 가정은 스토어 앱 자신만 지킵니다. 운영 CI 가 올릴 때 `--build` 를 번들 값과
맞추기 때문입니다. 다른 앱은 올리는 사람이 번호를 맞출 이유도, 방법을 알 이유도
없습니다.

워커는 서명하면서 번들의 `CFBundleVersion` 을 이미 읽어 서버에 알리고 있었습니다. 서버는
그 값이 빌드 번호와 다르면 로그만 남기고 버렸습니다.

## 결정

**서버가 워커가 알린 `CFBundleVersion` 을 버전에 적고(`bundle_version`), 스토어 앱은 깔린
번들의 같은 값과 견줍니다.** 스토어의 빌드 번호는 지금처럼 앱 안의 순서와 겹침 검사에만
씁니다.

견주는 순서:

1. 서버가 번들 값을 알면 깔린 번들의 `CFBundleVersion` 과 견준다
2. 모르고, 깔린 쪽이 정수면 지금처럼 빌드 번호와 견준다. 스토어 앱 자신과 이 칸이 생기기
   전에 서명한 버전이 여기로 온다
3. 그것도 안 되면 버전 문자열(`CFBundleShortVersionString`)로 견준다

견주는 법은 같은 문자열이면 최신, 아니면 점으로 나눠 앞에서부터 숫자로 봅니다. 모자란
자리는 0 입니다. 숫자가 아닌 조각이 있으면 "비교 불가" 로 둡니다.

## 대안과 기각 사유

### 빌드 번호를 번들 값으로 고친다

서버가 이미 번들의 버전 문자열은 번들 값으로 고칩니다. 빌드 번호도 그렇게 하면 칸이
늘지 않고, 스토어 앱의 비교 코드도 그대로 둘 수 있습니다.

기각합니다. 빌드 번호는 정수이고 앱 안에서 겹칠 수 없습니다. `1.8.25` 는 정수로 담을 수
없고, 정수라도 서명이 끝난 뒤에 고치면 다른 버전과 겹칠 수 있는데 그 충돌을 풀 방법이
서버에 없습니다.

### 올릴 때 번들 값과 같은 빌드 번호를 요구한다

스토어 앱처럼 모든 앱이 `--build` 를 맞추면 두 번째 가정이 참이 됩니다.

기각합니다. 올리는 사람에게 스토어 내부의 규칙을 떠넘깁니다. 웹 콘솔로 올리는 사람은
빌드 번호 칸이 있는지도 모르고, `1.8.25` 같은 값은 여전히 담을 수 없습니다.

### 스토어 앱에서 버전 문자열로만 견준다

서버를 고치지 않아도 됩니다. 이미 출시된 앱에도 바로 통합니다.

기각합니다. 버전 문자열은 같은데 빌드만 다른 경우(같은 1.2.0 을 다시 빌드한 것)를
가르지 못합니다. 그래서 번들 값을 모를 때의 마지막 폴백으로만 씁니다.

## 결과

### 좋은 점

- `CFBundleVersion` 을 어떻게 적든 스토어가 따라갑니다. 올리는 사람이 맞출 것이 없습니다
- 이미 출시된 버전도 다시 올리지 않고 폴백으로 풀립니다
- 서버가 버리던 값을 쓰는 것이라 워커는 바뀌지 않습니다

### 나쁜 점

- 판단 경로가 셋이 됐습니다. 어느 경로로 판정했는지는 화면에 드러나지 않아서, 표시가
  틀리면 셋을 차례로 의심해야 합니다
- 폴백(버전 문자열)은 같은 버전의 재빌드를 "최신" 으로 봅니다. 이 칸이 생기기 전에
  서명한 버전에만 해당하고, 새로 올리면 사라집니다
- `1.0-beta` 처럼 숫자가 아닌 값은 여전히 "비교 불가" 입니다. 짐작해서 틀리는 것보다
  낫다고 봤습니다

### 후속 과제

- 웹 콘솔 버전 목록에 번들의 `CFBundleVersion` 을 함께 보여줄지. 지금은 스토어의 빌드
  번호만 보입니다
