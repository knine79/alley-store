# ADR-0040: 새 버전도 파일만 놓게 한다

- 상태: 수락됨
- 날짜: 2026-09-11

## 맥락

이 스토어에 앱을 올리는 사람은 **macOS 개발자가 아닙니다.** AI 와 함께 만든 앱을
올립니다. 그런데 새 버전 화면은 이렇게 물었습니다.

| 칸 | 이 사람이 아는가 |
| --- | --- |
| 앱 파일 | 안다 |
| 버전 | 안다 |
| 빌드 번호 | **모른다** |
| 최소 macOS 버전 | **모른다** |
| 릴리즈 노트 | 안다 |

설명도 그 사람 것이 아니었습니다 - "`CFBundleShortVersionString` 과 맞추세요",
"`.app` 번들은 디렉터리라 그대로 올릴 수 없습니다".

**모르는 것을 세 개나 물으면서, 그 답이 전부 파일 안에 있었습니다.**

새 앱 등록은 이미 드래그앤드롭 두 단계로 고쳤습니다([ADR-0033](0033-drop-file-first-then-confirm.md)).
새 버전만 옛 모양으로 남아 있었습니다.

## 결정

같은 두 단계로 맞춥니다.

```
파일을 놓는다 → 읽은 값을 보여준다 → 바뀐 것만 적는다 → 올린다
```

**읽은 값은 보여주기만 합니다.** 고치라고 내놓지 않습니다. 버전·빌드·필요한 macOS
를 한 줄로 늘어놓고, 맞으면 그대로 올립니다. 사람이 채우는 칸은 "무엇이 바뀌었나요?"
하나뿐이고 그것도 선택입니다.

읽지 못했을 때만 묻습니다. zip64 나 우리가 모르는 압축 방식이면 그때 칸이 나옵니다.
dmg 는 아무것도 묻지 않고 올린 뒤에 읽습니다([ADR-0034](0034-worker-decides-bundle-id-for-disk-images.md)).

### 다른 앱 파일이면 놓는 순간 막습니다

새 버전은 어느 앱에 올리는지가 정해져 있습니다. zip 이면 브라우저가 번들 ID 를
읽을 수 있으므로, 등록된 값과 다르면 **그 자리에서 거절합니다.**

예전에는 몇백 MB 를 다 보낸 뒤 서명 직전에 막혔습니다([ADR-0029](0029-verify-bundle-identifier-before-signing.md)).
브라우저가 이미 아는 것을 스토리지까지 다녀와서 알려줄 이유가 없습니다.

### 막을 때는 무엇을 해야 하는지 함께 말합니다

빌드 번호가 겹치면 예전에는 "빌드 번호 42 는 이미 쓰였습니다" 였습니다. 빌드 번호를
모르는 사람에게 번호만 알려주면 어디를 고쳐야 하는지 알 수 없습니다. 지금은 무엇이
이미 올라가 있는지와, 몇 번 이상으로 올려 다시 만들어야 하는지를 말합니다.

## 대안과 기각 사유

**읽은 값을 고칠 수 있게 둔다** — 값이 틀렸을 때 손으로 바로잡을 수 있습니다.
그러나 **틀릴 일이 거의 없고**, 고칠 수 있게 두면 "고쳐야 하나" 를 매번 판단하게
됩니다. 파일과 다른 값을 적으면 서명 단계에서 어긋나기만 합니다. 정말 다르면 파일을
다시 만드는 것이 맞습니다.

**접어서 숨긴다** — 값을 보여주면서 칸도 남깁니다. [ADR-0033](0033-drop-file-first-then-confirm.md)
에서 이미 겪었습니다. **접힌 것도 "열어서 채워야 하나" 로 읽힙니다.**

**화면을 그대로 두고 설명만 쉽게 쓴다** — 가장 작은 변경입니다. 그러나 모르는 것을
묻는다는 사실이 바뀌지 않습니다. 설명을 길게 쓸수록 읽을 것만 늘어납니다.

## 결과

**좋은 점**

- **사람이 채우는 칸이 셋에서 영(선택 하나)으로 줄었습니다**
- 다른 앱 파일을 놓으면 올리기 전에 막습니다. 몇백 MB 를 헛되이 보내지 않습니다
- 새 앱 등록과 같은 모양입니다. 한 번 해본 사람은 두 번째를 배우지 않아도 됩니다
- 막는 메시지가 무엇을 해야 하는지 말합니다

**나쁜 점**

- **파일의 값이 틀렸을 때 웹에서 바로잡을 방법이 없습니다.** 파일을 다시 만들어야
  합니다. 의도한 맞바꿈이지만, 급할 때는 답답합니다. CLI 는 `--version` 으로 여전히
  덮어쓸 수 있습니다
- **번들 ID 대조는 zip 에만 됩니다.** dmg 는 브라우저가 못 여니 다른 앱 파일이어도
  다 올린 뒤에야 막힙니다
- 화면 하나가 늘었습니다. 파일을 고르고 바로 올리던 것이 이제 확인 화면을 지납니다.
  대신 그 화면에서 묻는 것이 거의 없습니다
