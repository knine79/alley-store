# ADR-0074: 실행 중인 앱은 버전마다 한 번 종료하고 업데이트할지 묻는다

- 상태: 수락됨
- 날짜: 2026-10-06

## 맥락

ADR-0073 은 실행 중인 앱을 자동 업데이트에서 건너뛰고 다음 확인 때 다시 보게 했습니다.
쓰는 중에 바꿔치면 저장하지 않은 작업이 날아가기 때문입니다.

그 결과 늘 떠 있는 앱은 자동으로는 업데이트되지 않습니다. 메뉴바 앱처럼 로그인할 때 켜져
내내 떠 있는 앱이 그렇습니다. ADR-0073 이 나쁜 점으로 적어둔 것인데, 운영에서 "실행 중인
앱은 그냥 건너뛰는 거냐" 는 질문이 바로 나왔습니다.

## 결정

**실행 중이라 건너뛴 앱이 있으면, 스토어 앱이 앞에 나와 있을 때 얼럿 하나로 "종료하고
업데이트" 할지 묻습니다. 버전마다 한 번만 묻습니다.**

- 대상은 자동 업데이트 대상과 같고(업데이트 있음 상태) 실행 중이라는 것만 다릅니다.
  앱 자동 업데이트를 끈 사람에게는 묻지 않습니다
- 여러 앱을 한 얼럿에 묶습니다. 문구는 이렇습니다

  ```
  실행 중인 앱에 업데이트가 있습니다
  Aquarium, Picboard
  앱을 종료하고 업데이트한 뒤 다시 실행합니다.
  저장하지 않은 작업이 있으면 앱이 먼저 물어봅니다.
  [나중에] [종료하고 업데이트]
  ```

- "나중에"(또는 Esc)를 누른 버전은 다시 묻지 않습니다. 물어본 출시본의 버전 ID 를 앱마다
  그 맥의 `UserDefaults` 에 적어 두고, 새 버전이 나와 ID 가 바뀌면 다시 묻습니다. 목록의
  "업데이트" 버튼은 그대로 남습니다
- 스토어 앱이 뒤에 있을 때 찾은 것은 앞으로 나올 때 묻습니다
- "종료하고 업데이트" 는 앱마다 `NSRunningApplication.terminate()` 로 정상 종료를 요청하고
  30초까지 기다립니다. 종료되면 업데이트한 뒤 다시 실행하고, 안 되면 강제 종료하지 않고
  그 앱만 건너뜁니다. 끝나면 결과를 한 줄로 알립니다
  ("앱 2개를 업데이트했습니다." / "종료되지 않아 건너뛴 앱: Aquarium")
- 얼럿이 떠 있는 동안은 스토어 앱 자신을 갈아끼우지 않습니다. 갈아끼우면 스토어 앱이
  종료되면서 얼럿이 사라집니다

## 대안과 기각 사유

### 확인할 때마다 묻는다

**놓치는 업데이트가 없습니다.** "나중에" 를 눌러도 30분 뒤에 다시 기회가 옵니다.

기각한 이유는 30분마다 같은 얼럿이 뜨면 사람들이 읽지 않고 닫게 되기 때문입니다. 그러면
정말 필요한 업데이트도 같은 손놀림에 묻힙니다. 버전마다 한 번이면 새 버전이 나올 때마다
한 번씩만 방해합니다.

### 얼럿 대신 목록 위 배너

**아무도 방해하지 않습니다.** 스토어 앱을 열면 보이고, 원할 때 누릅니다.

기각한 이유는 스토어 앱을 열 일이 드물어서입니다. 자동 업데이트가 켜진 사람은 스토어 앱을
거의 열지 않고, 배너는 그 사람에게 보이지 않습니다. 얼럿은 스토어 앱이 앞에 나왔을 때만
뜨므로 방해도 그때뿐입니다.

### 종료되지 않으면 강제 종료한다

**업데이트가 확실히 끝납니다.**

기각한 이유는 앱이 저장할지 묻는 창에서 사람이 취소했을 수 있기 때문입니다. 강제 종료하면
그 작업이 날아갑니다. 업데이트가 늦는 편이 작업을 날리는 것보다 낫다는 설계 문서의 교체
절차를 따릅니다.

## 결과

**좋은 점**

- 늘 떠 있는 앱도 사람이 한 번 누르면 업데이트됩니다
- 같은 버전으로는 한 번만 방해합니다

**나쁜 점**

- "나중에" 를 누른 버전은 사람이 목록에서 직접 누르기 전까지 남습니다. 다음 버전이 나와야
  다시 묻습니다
- 스토어 앱을 앞으로 가져오지 않는 사람에게는 묻지 못합니다
- 종료를 요청한 뒤 사람이 저장 창에서 오래 머물면 30초가 지나 그 앱은 건너뜁니다. 저장은
  끝났는데 업데이트는 안 된 채로 앱이 꺼져 있을 수 있습니다
- 물어본 기록이 맥마다 따로라, 같은 사람이 맥을 바꾸면 다시 묻습니다

**후속**

- 건너뛴 앱을 그 앱이 종료될 때 업데이트하는 길(`NSWorkspace.didTerminateApplicationNotification`)을 검토합니다
